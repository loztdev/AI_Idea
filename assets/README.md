# Assets Directory

This directory contains app assets like icons and splash screens.

For a production app, you would need to add:
- icon.png (1024x1024)
- splash.png (recommended 1284x2778)
- adaptive-icon.png (Android, 1024x1024)
- favicon.png (Web, 48x48)

You can generate these using tools like:
- https://www.appicon.co/
- https://apetools.webprofusion.com/app/#/tools/imagegorilla
- Figma or other design tools

For now, Expo will use default placeholders.
